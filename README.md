# price_detection
Автоматическое извлечение данных с ценников продуктов

Стек: Python, PyTorch, OpenCV, EasyOCR, YOLO, HuggingFace Transformers, Pandas

Решение: Создала автоматизированный пайплайн для извлечения названия категории продукта и цены с изображений ценников в магазине. 

Разработала многоступенчатый конвейер:

1. Детекция ценника на изображении и информации с него с помощью YOLO.
2. Распознавание цифр цены с использованием EasyOCR (только цифры).
3. Распознавание текста на ценнике с помощью EasyOCR.
4. Классификация текста по категориям продуктов с помощью предобученной модели BERT (DeepPavlov/rubert-base-cased), дообученной на 57 классах.


Написаны вспомогательные функции для обработки изображений (расширение bounding box, фильтрация текста).
Организована работа с большим объёмом изображений (партиционирование, очистка GPU, прогресс-бар). 
Результат: Пайплайн автоматически обрабатывает изображения, определяет категорию продукта и цену, что позволяет в дальнейшем применять его для инвентаризации или аналитики торговых точек.
